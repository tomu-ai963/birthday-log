# birthday-log（誕生日メモ）

誕生日と命日を記録し、次の誕生日・命日が近い順に「あと○日」を表示する静的Webアプリです。

- `index.html` 1ファイルのみ（外部ライブラリなし・ビルド不要）
- データはブラウザの localStorage に保存（端末内のみ）
- 種別は「人」「ペット」のほか、自分で入力することもできます
- 命日は任意。登録すると誕生日は「生まれて○年」、命日は「亡くなって○年」で表示します
- 登録した内容はあとから編集できます（命日の追記など）
- 2月29日生まれ（没）は、うるう年以外は2月28日として扱います
- スマホ幅（375px）対応

公開URL: https://tomu-ai963.github.io/birthday-log/
